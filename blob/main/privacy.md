
# Privacy Policy


## Overview
This application analyzes Pinterest pin data for duplicate detection and quality assessment. This is a research/educational project.

## Data Collection
- We access publicly available Pinterest pin data via API
- No personal user data is stored permanently
- All data processing happens locally/temporarily

## Data Usage
- Pin images and metadata are analyzed for similarity
- Results are used for quality ranking
- No data is shared with third parties

## Data Storage
- Temporary processing only
- No long-term storage of user data
- Image embeddings may be cached temporarily for performance

## User Rights
Users can request:
- Data deletion
- Access to their data
- Information about data usage

## Changes
We may update this policy. Check this page for updates.
